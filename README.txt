============================================================
 SHOPEE AFFILIATE SCRAPER PRO v2.8.2 (UGC Media & Data Enricher)
============================================================

Ekstensi Chrome untuk mengumpulkan dan memperkaya data produk Shopee Affiliate dengan data siap konversi (sesuai formula konversi Threads & audiens mom-mom):
- 📥 Import CSV Asli Shopee Affiliate: Otomatis membaca ratusan link dari file CSV bawaan affiliate.
- 📸 Gambar dari Ulasan Pembeli (UGC): Menangkap 15-30 foto ulasan asli pembeli bintang 4-5 (format JSON dalam 1 kolom CSV baru) untuk konten natural dan anti-iklan.
- 💬 Ulasan Kritis (Bintang 3-4): Menangkap ulasan keluhan fungsi riil pembeli untuk bahan HOOK & batasan masalah objektif.
- ⭐ Ulasan Bukti (Bintang 5): Menangkap testimoni pengalaman pembeli berkualitas untuk bahan PROOF & SOLUSI.
- 📋 Tabel Spesifikasi Produk: Menangkap bahan, ukuran, tipe untuk bahan konversi "Fitur vs Manfaat".
- 📈 Validasi Rating & Terjual: Menangkap data rating bintang dan jumlah terjual riil Shopee untuk social proof.
- 🔗 Ambil Link Langsung Video (.mp4): Menyalin link CDN video asli seller.
- 🖼️ Ambil 4 - 6 Link Gambar: Menyalin link CDN hingga 4 - 6 gambar HD galeri produk (ambil maksimal 6 jika ada, atau 4-5 sesuai ketersediaan produk).
- 📝 Ambil Deskripsi Lengkap: Menyalin isi deskripsi produk tanpa terpotong.
- ⚡ Tanpa Download File Lokal: Sangat cepat, hemat kuota internet, dan tidak memakan kapasitas disk.
- 📊 Ekspor CSV Baru (Enriched): Menambahkan kolom: "Link Video", "Link Gambar 1-6", "Deskripsi Lengkap", "Rating", "Terjual", "Review Kritis (Bintang 3-4)", "Review Bukti (Bintang 5)", "Spesifikasi", dan "Gambar Ulasan (JSON)".


CARA INSTALASI / REFRESH DI CHROME:
-----------------------------------
1. Buka browser Chrome, buka tab baru: chrome://extensions
2. Aktifkan toggle "Developer mode" di pojok kanan atas.
3. Klik tombol "🔄 Reload" pada kartu ekstensi Shopee Affiliate Scraper Pro.
   (Atau "Load unpacked" jika baru pertama kali, lalu pilih folder ini).
4. Selesai!


ALUR PENGGUNAAN CSV ENRICHER:
-----------------------------
1. GENERATE & DOWNLOAD CSV DARI SHOPEE AFFILIATE
   - Buka portal affiliate.shopee.co.id
   - Buat penawaran / custom link massal (misal 50 atau 100 produk).
   - Download file CSV bawaan Shopee Affiliate tersebut.

2. IMPORT KE SHOPEE SCRAPER PRO
   - Buka https://shopee.co.id atau https://affiliate.shopee.co.id
   - Panel Shopee Scraper Pro otomatis muncul di pojok kanan bawah.
   - Buka menu "📥 Import CSV / Tempel Link Affiliate".
   - Klik tombol hijau "📁 Upload / Import File CSV Shopee" dan pilih file CSV tadi.
   - Semua link affiliate dan nama produk langsung masuk antrian secara otomatis.

3. MULAI PENGAYAAN DATA (ENRICHMENT)
   - Klik tombol "▶ Mulai Ambil".
   - Bot akan membuka tab produk di latar belakang satu per satu secara santai (anti-blokir/anti-captcha).
   - Bot menangkap video (.mp4), gambar, deskripsi, rating, terjual, ulasan kritis (bintang 3-4), testimoni bukti (bintang 5), dan spesifikasi.
   - Tab otomatis tertutup sendiri setelah data tertangkap.

4. UNDUH CSV BARU / SALIN FORMAT BOT
   - Masuk ke tab "Hasil & Unduh".
   - Klik tombol utama: "📊 Unduh CSV Baru (+ Link Video, Gambar & Deskripsi)".
   - Atau klik "📋 Salin Format Bot" untuk langsung menempelkan seluruh data riset siap pakai ke prompt generator Threads bot!
